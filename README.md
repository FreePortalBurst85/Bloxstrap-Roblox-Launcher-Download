## 🧠 Overview

**Bloxstrap Roblox Launcher** is an alternative Roblox bootstrapper for Windows that adds extra customization, management, and convenience features to the standard Roblox launching experience. It provides a dedicated configuration environment for users who want more control over how Roblox starts and behaves on their computer.

The launcher includes customizable visual elements, local asset modifications, activity tracking, Discord Rich Presence, server information, and additional configuration options. Users can also personalize the Roblox experience with community-created modifications while keeping those changes organized separately from the standard client files.

Bloxstrap is designed as a lightweight companion for Roblox players who want additional desktop controls and personalization without replacing the underlying Roblox client.

## Additional Information for Windows Users

Bloxstrap provides a centralized way to customize and manage the Roblox desktop experience while leaving the underlying game client intact. Its customization system can handle supported local assets and community modifications without requiring users to repeatedly replace files after Roblox updates.

Activity tracking can operate in the background and enables additional functionality such as Discord Rich Presence, server location information, game history, and other session-related features.

The launcher also includes supported engine configuration options based on Roblox's Fast Flag system. Available options can change as Roblox updates its client and restricts certain settings, so individual features may vary between versions.
